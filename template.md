# Short title that names the problem

**Tested on:** OS / tool versions / hypervisor

**Area:** Windows | Linux | Virtual lab | Android lab | Azure

## Symptom
What you see: the exact error message or behavior.

## Cause
Why it happens, in a sentence or two.

## Fix
Numbered steps or commands. Say where each command runs (host, Ubuntu VM, PowerShell as admin, and so on).

## Verify
How to confirm it worked.

## Undo
How to revert, if the fix changes system settings.

## Notes
Caveats, alternatives, links.
